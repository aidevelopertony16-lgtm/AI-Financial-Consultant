# 📈 AI Financial Consultant | المستشار المالي الذكي

An AI-powered web application that analyzes economic news and predicts its impact on oil prices using Google's Gemini API.
تطبيق ويب مدعوم بالذكاء الاصطناعي يحلل الأخبار الاقتصادية ويتنبأ بتأثيرها على أسعار النفط باستخدام واجهة جيميناي من جوجل.

## 🚀 Features | المميزات
* **News Analysis:** Reads economic text and determines market sentiment (Bullish/Bearish). (تحليل الأخبار وتحديد اتجاه السوق).
* **Logical Reasoning:** Explains the economic reasons behind the prediction. (شرح الأسباب الاقتصادية وراء التوقع).
* **Fast & Reliable:** Powered by Gemini's cloud infrastructure. (سريع وموثوق بفضل بنية جوجل السحابية).

## 🛠️ Tech Stack | التقنيات المستخدمة
* Python
* Gradio
* Google GenAI (Gemini API)
